# Your Friendly Irs Buddy Webapp 
Friendly IRS website implemented with plain HTML, CSS and Javascript.

It uses [Deno](https://deno.com/) to:
- serve static files on a specific port
- build a minified webapp into `dist/` folder.

## Development
- Run development server: `deno task dev`
- Build webapp: `denot ask build` 
- Format: `deno task fmt`
- Lint: `deno task lint`
